# Libft

## What this does
Custom C library reimplementing standard functions (string, memory, etc.).

## Why it matters
Provides a reusable foundation for C projects and improves understanding of core programming concepts.

## Features
- String manipulation functions
- Memory management utilities
- Linked list support

## Example
ft_strlen("hello"); // returns 5

## How to use
Include the library in your project and compile:
make
